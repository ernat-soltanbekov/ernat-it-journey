# Escalation template

Adapted from [incident reports](../incident_report_1.md) and [support notes](../support_notes.md). Copy into a new note for a real or clearly labeled training case.

- **Case type:** real incident / training scenario
- **Observed at:** actual date, time, timezone
- **Impact and scope:** affected users, action blocked, known start time
- **Symptom:** exact message and expected versus observed behavior
- **Reproduction:** environment, method, sanitized URL, minimal steps
- **Evidence:** status, sanitized response, request ID, relevant log excerpt
- **Checks completed:** action → observation; include checks that ruled out a hypothesis
- **Working hypotheses:** reason for each; keep separate from confirmed findings
- **Workaround:** tested effect and constraints, or none established
- **Requested next action:** specific owner and diagnostic check
- **Next update:** agreed time or triggering event

Quality check: a colleague can continue without guessing the environment or repeating completed checks. Remove credentials and unnecessary personal data. Do not paste a password into a ticket or ask a user to disclose it.
